## The Concept in One Sentence

A dark-mode web installation in which the Victoria Line is rendered as a living circulatory system: amber boluses of light pulse down a vein-like artery at the speed of real trains, each station flaring with a halo colour drawn from the demographic makeup of its surrounding ward.

---

## The Art Moment (non-negotiable)

**The Bloodstream** — see BRAINSTORM.md §2 for full rationale. Every other feature serves this moment. If a design decision makes the boluses less beautiful or the halos less meaningful, it is the wrong decision.

### M2 — Static Data Ingestion (Day 2)
**Goal:** all slow/static data fetched once, committed as JSON, queryable by the backend.

**Victoria Line station data (`/backend/data/victoria_line.json`):**
```json
[
  { "id": "940GZZLUBXN", "name": "Brixton", "lat": 51.4627, "lng": -0.1145, "zone": 2, "sequence": 1 },
  ...
]
```
All 16 stations, in line order (Brixton → Walthamstow Central). Coordinates from TfL static data / OSM.

**Borough demographics (`/backend/data/demographics.json`):**
- Source: ONS NOMIS API — ward-level deprivation index, median income, top 3 non-English languages, % born outside UK
- Scope: wards intersecting the Victoria Line corridor (Westminster + Lambeth + Hackney + Waltham Forest)
- Script: `scripts/fetch_demographics.py` — runs once, writes JSON, committed

**Amenity counts (`/backend/data/amenities.json`):**
- Source: Overpass API — pubs, cafes, places of worship, bookmakers within 400m of each station
- Script: `scripts/fetch_amenities.py` — runs once, writes JSON, committed

**Halo colour map (`/backend/data/halo_colours.json`):**
- Derived from demographics: deprivation index → colour temperature formula (see BRAINSTORM.md §5)
- Generated by `scripts/compute_halos.py` after demographics fetch

All static data committed to the repo. No database needed for the PoC — the backend reads from JSON files on startup.

### M3 — TfL Bridge (Day 3)
**Goal:** `/api/live-trains` endpoint returns clean, cached arrival data; all TfL calls proxied through backend.

**Endpoints:**
| Route | Method | Description |
|---|---|---|
| `/api/live-trains` | GET | Cached snapshot: all Victoria Line arrivals, shape below |
| `/api/station/{id}` | GET | Station metadata + demographics + amenity facts |
| `/api/line-pressure` | GET | `{ running: N, scheduled: N, ratio: 0.0–1.0 }` |
| `/health` | GET | `{ status: "ok", last_tfl_fetch: ISO8601 }` |

**Live trains response shape:**
```json
{
  "fetched_at": "2026-06-07T14:23:00Z",
  "trains": [
    {
      "vehicle_id": "...",
      "towards_station_id": "940GZZLUBXN",
      "towards_station_name": "Brixton",
      "time_to_station_seconds": 45,
      "direction": "southbound",
      "current_location": "Between Stockwell and Brixton"
    }
  ]
}
```

**Scheduler:** APScheduler background job fetches TfL `/Line/victoria/Arrivals` every 20 seconds, stores snapshot in module-level dict. All client requests read from the dict — TfL is never called from the frontend.

**TfL API key:** Free, no payment. Requires registration at `api.tfl.gov.uk`. This is a **hard-stop credential** — the human must register and provide `TFL_APP_KEY` as an environment variable. Log in DECISIONS.md. Backend gracefully degrades (returns cached or empty) if key is absent.

### M5 — The Art (Day 4–6)
**Goal:** The piece looks and feels like art. This is the milestone that matters.

#### 5a — The Bloodstream Animation

The core Canvas animation loop. Runs at 60fps via `requestAnimationFrame`.

**Artery path:** A smooth bezier curve connecting all 16 station nodes in sequence, drawn on the canvas. Stroke colour: `rgba(255, 160, 40, 0.15)` — barely visible amber, the vein wall.

**Bolus objects:** For each train in `trainState`:
- Compute parametric position `t` along the artery path from `time_to_station_seconds` and estimated inter-station travel time
- Render as: a radial gradient centred at the computed position, innermost colour `rgba(255, 200, 80, 0.95)` fading to transparent, radius ~12px
- Animate: on each frame, recompute `t` from updated clock (no re-fetch needed between polls)

**Station flares:** When a bolus is within 60 seconds of a station:
- Draw expanding concentric rings at the station node, colour from `halo_colours.json`
- Ring opacity inversely proportional to `time_to_station_seconds` — fully saturated at 0s, invisible at 60s

**Arrhythmia:** If a station's `incident_count > threshold`, introduce a ±200ms jitter to that station's flare timing. Imperceptible as a fact, felt as a texture.

#### 5b — Atmosphere Shifts

**Background colour temperature:** CSS custom property `--map-tint` set as a function of the user's current map centre latitude. Computed on map `moveend` event. Applied as a subtle `mix-blend-mode: color` layer over the map.

**Typography weight:** Station label `font-weight` set from `halo_colours.json`'s wealth score. Range: 300 (outer, less wealthy) to 600 (central, wealthy). Set on marker creation.

#### 5c — Station Heartbeat Panel

Replace placeholder sidebar with the full panel:

**Structure:**
1. **Dot-matrix arrival board** (top 40% of panel) — canvas or CSS dot-matrix font rendering next 3 trains from TfL live data. Font: `Courier Prime` or a custom dot-matrix web font. Colour: `#FF9900` on `#1a0a00` background.
2. **Scrolling facts feed** (bottom 60%) — same dot-matrix font, scrolling upward at ~20px/s, displaying:
   - Demographics sentence (generated from `demographics.json`)
   - Amenity fact (from `amenities.json`)
   - Wikipedia "On This Day" item (fetched from Wikipedia REST API)
3. **Open/close animation:** CSS `transform: translateX(100%)` → `translateX(0)`, 300ms ease-out. Feels like a platform door.

#### 5d — Line Pressure Gauge

Left-edge vertical SVG gauge. Needle position = `line-pressure.ratio`. Colour zones: green (>0.8), amber (0.5–0.8), red (<0.5). No numbers. Always visible.

#### 5e — Arrival Sound (optional, enable via URL param `?sound=1`)

Web Audio API. On each station flare:
```javascript
const tone = new OscillatorNode(ctx, { frequency: 220 + (station.sequence * 15) });
// short 80ms sine burst, gain envelope
```

## Risks

| Risk | Mitigation |
|---|---|
| TfL API rate limiting | Backend caches one snapshot per 20s, serves all clients from cache. Never call TfL from frontend. |
| Generic-looking visuals | Amber-only palette, Johnston/dot-matrix fonts, no cyan, no particles for their own sake. See BRAINSTORM.md §7. |
| Scope creep | Everything beyond one line / one borough is Phase 2. Plan is complete as specified. |
| Railway free tier limits | 500 hours/month = ~16 hours/day. Sufficient for a PoC. If it exceeds limits, move to Render free tier. |
| Mapbox token exposure | Use environment variable injection at build time, or switch to CartoDB tiles (no token). |
